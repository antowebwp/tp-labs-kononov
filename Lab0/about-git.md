# Лабораторная работа 0. Система контроля версий Git и сервис GitHub

## 1. Чем ветка отличается от копии папки с проектом?

Ветка — это отдельная линия работы внутри одного репозитория с общей историей коммитов. При переключении ветки Git меняет файлы в рабочей папке, поэтому вручную копировать весь проект не нужно. Изменения из разных веток можно сравнивать и объединять с помощью Git.

## 2. Что произойдёт с историей, если удалить папку проекта, но сохранить .git?

Если удалить рабочие файлы, но полностью сохранить папку `.git`, история локальных коммитов останется в ней. Файлы из последнего коммита можно восстановить, например командой `git restore .` из корня репозитория, если удаление ещё не добавлено в индекс. Незакоммиченные изменения и файлы, которые Git не отслеживал, таким способом восстановить нельзя.

## 3. Зачем нужен Pull Request, если можно коммитить сразу в main?

Pull Request позволяет показать изменения из отдельной ветки до их включения в `main`. Преподаватель или другой участник может посмотреть разницу, оставить замечания и дождаться исправлений. Основная ветка получает изменения после проверки, а обсуждение работы сохраняется вместе с PR.
