# Lab3 — вариант 1

```text
dotnet run --project Lab3
```

Введите строки текста; пустая строка завершает ввод. Выберите существующую папку, имя и UTF-8, Windows-1251 или CP866. Размеры рассчитываются для всех трёх кодировок без BOM, с переводом строки после каждой введённой строки. Для символов, отсутствующих в кодировке, программа сообщает о невозможности сохранения без потерь.

Текст сначала записывается во временный файл, затем обрабатывается асинхронно блоками; весь текст в память не загружается. Существующий файл перезаписывается только после подтверждения. Запись выполняется через временный файл в целевой папке, поэтому ошибка кодировки не уничтожает предыдущий файл.

За основу взята исходная Lab2. Изменены завершение ввода, разделение логики и консоли, потоковая обработка и подсчёт размеров. Проверены пустой текст, кириллица, все кодировки, недопустимые имена и символ Unicode на границе буфера.
