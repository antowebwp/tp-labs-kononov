# Lab4 — тестирование кода Lab1 и Lab2

```text
dotnet build Lab4/Lab4.slnx
dotnet test Lab4/Lab4.slnx
dotnet test Lab4/Lab4.slnx --collect:"XPlat Code Coverage"
```

Lab4.Core содержит четыре алгоритма варианта 1 и классы Vehicle, Car, Truck, Bus, Garage из веток lab1/lab2. Библиотека не зависит от консоли и от наличия других лабораторных в main.

38 тестовых случаев, 27 тестовых методов: параметризованные проверки, нулевые значения, пустой гараж, BigInteger за пределами long, неверные аргументы, стоимость поездки, изменение коллекции, сортировка и группировка. Подготовка, вызов и проверка разделены пустыми строками.

Проверка чувствительности: временная замена начального значения факториала с 1 на 0 приводит к падению тестов; после возврата исходного кода тесты проходят.

Измеренное покрытие Lab4.Core: 84.25% строк и 76% ветвей. Не все варианты ошибок конструкторов и форматирования ToString покрыты. Отчёт создаётся в Lab4.Tests/TestResults; он не включается в Git.
