# Lab6 — TCP-чат

Из корня репозитория, в отдельных терминалах VS Code:

```text
dotnet build Lab6/Lab6.slnx
dotnet run --project Lab6/ChatServer -- 5555
dotnet run --project Lab6/ChatClient -- localhost 5555
```

Запустите два или три клиента с разными никами. Порт сервера по умолчанию 5555; допустимы порты 1–65535. Для локальной сети вместо localhost укажите адрес компьютера сервера.

Команды: /list — список пользователей; /w ник текст — личное сообщение; /exit — выход. Ники уникальны без учёта регистра. При занятом нике клиент предлагает другой в том же соединении. Первой строкой передаётся ник, ответ сервера — OK или ERROR; дальнейшие сообщения разделяются переводом строки и кодируются UTF-8.

События и сообщения дозаписываются с датами в chat.log в рабочей папке сервера. Личные сообщения доступны отправителю, адресату и журналу сервера. Доступ к списку клиентов синхронизирован; запись каждому клиенту сериализуется SemaphoreSlim. Ctrl+C останавливает сервер и закрывает соединения.

Проверено на localhost: три клиента, повторный ник и повторный ввод, список, общий текст, изоляция личного сообщения, внезапный обрыв, повторное подключение, журнал, недоступный сервер. Исходная Lab3 использовала UDP multicast без сервера, поэтому обязательная TCP-архитектура реализована заново.
