# Lab5 — вариант 1

π по ряду Лейбница. Последовательная и параллельная версии используют одинаковые блоки по 100000 членов и суммируют результаты в фиксированном порядке. Это обеспечивает побитовое совпадение результатов независимо от порядка выполнения потоков. Parallel.For ограничивает степень параллелизма выбранным числом.

```text
dotnet run -c Release --project Lab5 -- 100000000 4
```

Без аргументов программа запрашивает параметры. Допустимо от 1 до 1000000000 членов и от 1 до 256 потоков. Ctrl+C отменяет расчёт через CancellationToken.

Замеры на этом Mac, Release, 100000000 членов. Перед измерениями выполнен короткий прогрев. Это по одному измерению для каждой настройки; время зависит от нагрузки системы.

| Потоки | Последовательно, мс | Параллельно, мс | Ускорение |
| --- | --- | --- | --- |
| 1 | 198.402 | 214.872 | 0.923× |
| 2 | 246.267 | 101.194 | 2.434× |
| 4 | 217.698 | 48.463 | 4.492× |
| 8 | 215.023 | 37.773 | 5.693× |
| 16 | 232.034 | 28.605 | 8.112× |

Во всех запусках результат 3.1415926435897199, ошибка относительно Math.PI — около 1.0000073×10⁻⁸. Добавление потоков не гарантирует ускорение: при одном потоке параллельный вариант медленнее из-за накладных расходов; предел определяется ядрами CPU, планировщиком и последовательной частью программы.
